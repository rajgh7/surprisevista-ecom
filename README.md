# 🎁 SurpriseVista - Premium Gifting & E-Commerce (React + Tailwind)

**SurpriseVista** is your one-stop destination for thoughtful gifting solutions — where creativity meets emotion.  
We curate and design gifts that tell stories, strengthen relationships, and spread smiles.  
Our catalogue includes **personalized gifts, surprise boxes, festive hampers, and customized experiences** for individuals and corporates alike.

---

## 🛍️ Project Overview

A **modern single-page eCommerce prototype** for SurpriseVista Gifts — built with **React + Tailwind CSS**, ready to deploy on **GitHub Pages**.

This project includes:
- Elegant, minimal UI design
- Product grid with add-to-cart functionality
- Checkout flow with enquiry form
- Integration-ready backend (Google Apps Script → Google Sheets)
- SEO-friendly and responsive structure
